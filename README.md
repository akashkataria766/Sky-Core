## 🌌 What is Sky Core?

Sky Core is an evolving personal AI platform built around **SKY**.

The idea is simple:

> **Don't just give me an answer. Help me understand why.**

SKY is designed to be practical, direct, analytical, honest, and capable of challenging ideas when necessary.

Sky Core is being developed as a real product experience rather than simply a demonstration of an AI API.

## 📱 Get Sky Core

### Android

The latest Android testing build is available through **GitHub Releases**.

### ⬇️ Download the APK

**Go to:**

**GitHub Repository → Releases → Latest Release → Assets → `Sky.Core.apk`**

The APK is attached to the latest release so you can download it directly without searching through the source code.

> ⚠️ Sky Core is currently in **Public Testing**. The APK is a testing build and may change as development continues.

### Android installation

1. Download **`Sky.Core.apk`** from the latest GitHub Release.
2. Open the downloaded APK on your Android device.
3. If Android asks for permission to install from that source, allow it.
4. Install and open **Sky Core**.
5. Start exploring SKY.

## 🚀 Getting Started

### 1. Start a conversation

Open Sky Core and begin talking with SKY.

Ask questions, discuss ideas, explain what you're working on, or simply start a conversation.

### 2. Give SKY context

Useful context helps SKY understand what you're trying to accomplish.

Continue conversations naturally instead of treating every message as completely separate.

### 3. Explore

Take some time to move through the application and discover what Sky Core can do.

Some parts of the experience are intentionally left for you to discover.

### 4. Share your experience

Try the application and form your own opinion.

**Positive, negative, critical, or unexpected feedback is welcome.**

You can share your opinion directly through the **Opinion Box inside Sky Core**.

## 🤖 Meet SKY

SKY is the personality at the heart of Sky Core.

SKY is designed to be:

- Practical
- Direct
- Curious
- Analytical
- Patient
- Honest
- Strategic
- Occasionally sarcastic
- Comfortable challenging weak ideas
- Able to adapt to conversation context

SKY doesn't have to agree with you.

If an idea doesn't make sense, SKY can explain why.

If information is missing, SKY can say so.

If a subject needs depth, SKY can go deeper.

And when a simple answer is enough, SKY keeps it simple.
